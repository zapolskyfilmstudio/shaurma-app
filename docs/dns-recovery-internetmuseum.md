# Восстановление DNS после смены A-записи интернетмузей.рф

## Что произошло

1. A-запись **интернетмузей.рф** указывает на VPS шаурмы.
2. Nginx отдавал кухню первому `server` блоку — поэтому на музее открывалась станция повара.
3. A-запись поддомена **мага.супер.повар.мегашаверма.рф** **удалена** (NXDOMAIN) — кухня по своему адресу не открывается.

**Временный обходной адрес (nginx на VPS уже настроен):** http://www.мегашаверма.рф

## Что уже сделано на сервере

Обновлён `infra/nginx.prod.conf`:

- кухня отдаётся **только** на `мага.супер.повар.мегашаверма.рф`;
- на `интернетмузей.рф` — заглушка «домен зарезервирован»;
- неизвестные домены не получают приложение шаурмы.

## Что нужно сделать в панели Beget

### 1. Домен мегашаверма.рф → DNS

Добавить **A-запись** для поддомена кухни:

| Поле | Значение |
|------|----------|
| Имя / поддомен | `мага.супер.повар` |
| Тип | A |
| Значение | IP вашего VPS шаурмы (тот же, что у мегашаверма.рф) |

Punycode (если панель просит полное имя):  
`xn--80aai8a.xn--e1atebk.xn--80ad9adi.xn--80aaahcle4cg3byf.xn--p1ai`

### 2. Домен интернетмузей.рф → DNS

**Удалить** A-запись на IP VPS шаурмы (тот же IP, что у мегашаверма.рф).

Для «пустого» домена на Beget можно:

- оставить A-запись на IP парковки Beget (`185.50.27.12`), или
- привязать домен к нужному хостингу музея, когда сайт будет готов.

Punycode: `xn--e1aaahcksfb3aueo.xn--p1ai`

## Скрипт через Beget API (опционально)

```bash
export BEGET_LOGIN='ваш_логин'
export BEGET_PASSWORD='ваш_пароль'
bash scripts/fix-beget-dns.sh
```

## Проверка

```bash
dig +short A xn--80aai8a.xn--e1atebk.xn--80ad9adi.xn--80aaahcle4cg3byf.xn--p1ai
# должно быть: IP VPS шаурмы

dig +short A xn--e1aaahcksfb3aueo.xn--p1ai
# НЕ должно быть IP VPS шаурмы
```

Кухня: http://мага.супер.повар.мегашаверма.рф  
Клиент: https://мегашаверма.рф
